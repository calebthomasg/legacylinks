Compare Safari and Chrome on iPhone

  1. Open this exact preview URL in Safari and Chrome on the same iPhone. Keep the same Wi-Fi or cellular connection for both tests.
  2. In each browser, tap Test GPS and respond to any location prompt. Keep the page open for up to 60 seconds.
  3. Compare permission, success or error, elapsed time, and accuracy. Note whether a website location prompt appeared. Coordinates are for your own inspection; you can omit them when reporting results.
  4. If a request receives no callback, reload before another test. You can repeat the comparison on cellular after recording the first pair.
